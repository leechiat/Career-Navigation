# AsyncAscent — Strategic Visibility & Autonomy Trainer (PWA)

## Quick GitHub Pages Deployment & Android Installation
1. Unzip `async-ascent-pwa.zip`.
2. Create a new repository on GitHub and upload all files (`index.html`, `manifest.json`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`) directly to the root of the repository.
3. Go to **Settings -> Pages**, under **Build and deployment**, select **Deploy from a branch**, choose `main` (and `/ (root)`), then click **Save**.
4. Open your live GitHub Pages URL (`https://<your-username>.github.io/<repo-name>/`) in **Chrome on your Android phone**.
5. Tap the **📲 Install App** button in the top bar (or open Chrome's 3-dot menu and tap **Install app** / **Add to Home screen**).
